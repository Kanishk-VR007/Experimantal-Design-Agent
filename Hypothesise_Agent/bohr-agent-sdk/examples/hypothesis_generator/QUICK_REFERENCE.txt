PRO TIPS:
─────────
• Always dry run first to preview queries and outputs
• Check if API key is detected (shown in dry run output)
• Experiment titles should be clear and specific
• Use domain-relevant terminology for better query generation
• Typical experiments compare 2-3 approaches or parameters

TROUBLESHOOTING:
────────────────
• "No module named 'arxiv'" → pip install arxiv python-dotenv requests
• No experiment → Add --experiment "title" or use interactive mode
• Want to see more papers → Add --max-papers 10
