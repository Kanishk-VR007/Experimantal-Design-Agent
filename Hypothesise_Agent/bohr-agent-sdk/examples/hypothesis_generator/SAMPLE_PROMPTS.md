## 🎯 Detailed Research Prompts

### Machine Learning

**Hyperparameter Tuning**
```
Investigate the effect of learning rate schedules (constant, exponential decay, cosine annealing) on ResNet-50 training performance for ImageNet classification
```

**Regularization Techniques**
```
Compare the effectiveness of dropout, L2 regularization, and data augmentation in preventing overfitting in convolutional neural networks for medical image classification
```

**Transfer Learning**
```
Evaluate the impact of pre-training dataset size on transfer learning performance when fine-tuning BERT for sentiment analysis on domain-specific text
```

### Computer Vision

**Object Detection**
```
Compare YOLO, Faster R-CNN, and EfficientDet architectures for real-time object detection in autonomous driving scenarios under varying lighting conditions
```

**Image Segmentation**
```
Analyze the effect of different loss functions (Dice, IoU, Focal Loss) on U-Net performance for medical image segmentation tasks
```

**Few-Shot Learning**
```
Evaluate few-shot learning approaches (Prototypical Networks vs MAML) for image classification with limited labeled data in wildlife species recognition
```

### Natural Language Processing

**Language Models**
```
Compare GPT-style autoregressive models vs BERT-style masked language models for text generation quality and coherence in creative writing tasks
```

**Named Entity Recognition**
```
Investigate the impact of different word embeddings (Word2Vec, GloVe, FastText, BERT) on NER performance across multiple languages
```

**Machine Translation**
```
Evaluate attention mechanisms (multi-head attention vs cross-attention) in transformer-based neural machine translation for low-resource languages
```

### Reinforcement Learning

**Algorithm Comparison**
```
Compare Q-Learning, Deep Q-Networks (DQN), and Proximal Policy Optimization (PPO) for training agents in continuous control tasks
```

**Reward Shaping**
```
Investigate the effect of different reward shaping strategies on training stability and convergence speed in robot manipulation tasks
```

### Time Series Analysis

**Forecasting**
```
Compare statistical methods (ARIMA) vs deep learning approaches (LSTM, GRU, Temporal Convolutional Networks) for multivariate time series forecasting in financial markets
```

**Anomaly Detection**
```
Evaluate autoencoder architectures vs isolation forest algorithms for real-time anomaly detection in IoT sensor data streams
```
